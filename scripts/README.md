## سكربت ترحيل صور التطبيقات 📸

هذا السكربت يقوم بترحيل صور التطبيقات من Telegram مباشرة إلى **ImgBB** لتخزينها على السحابة.

### الميزات ✨

- ✅ تحميل صور من Telegram بشكل آمن
- ✅ رفع مباشر إلى ImgBB Cloud
- ✅ تحديث قاعدة البيانات تلقائياً
- ✅ دعم معالجة الأخطاء والتكرار
- ✅ تشغيل تلقائي عند كل deployment

### الإعدادات المطلوبة 🔧

أضف هذه المتغيرات إلى ملف `.env`:

```env
IMGBB_API_KEY=your_api_key_here
DATABASE_URL=postgresql://...  # أو sqlite
BOT_TOKEN=your_bot_token
```

### التشغيل اليدوي 🚀

```bash
# تشغيل السكربت مباشرة
python scripts/migrate_images.py

# أو عبر Docker
docker build -t waleed-bot .
docker run --env-file .env waleed-bot
```

### التشغيل التلقائي ⚙️

عند نشر التطبيق على **Railway** أو أي منصة أخرى:

1. السكربت يعمل تلقائياً قبل بدء البوت
2. يفحص جميع التطبيقات بدون صور
3. يرفع الصور ويحدث قاعدة البيانات
4. يبدأ البوت بعده مباشرة

### المسارات 📁

- `scripts/migrate_images.py` - السكربت الرئيسي
- `integrations/imgbb.py` - موديول رفع ImgBB
- `entrypoint.sh` - نقطة الدخول للـ Docker

**ملاحظة**: إذا لم تعيّن `IMGBB_API_KEY` سيتم تخطي الترحيل تلقائياً.
